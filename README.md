# Football La Vida Trivia

A Python console quiz game for football fans.

## Features
- Name, age and gender validation
- Pick a favourite club: Chelsea, Manchester City, Barcelona, Real Madrid or Manchester United
- Three multiple-choice questions per club
- Score shown at the end

## How to run
1. Install Python 3
2. Run: python Main.py
